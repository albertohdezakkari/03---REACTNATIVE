# Cuaderno 0 · React Native con Expo

Web educativa interactiva construida con HTML5, CSS3 y JavaScript puro.

## Objetivo

Introducir la configuración mínima de Expo y practicar diseño visual con React Native mediante 10 ejercicios progresivos.

La secuencia pedagógica de cada ejercicio sigue:

**Orientación → Fundamentos → Representación → Práctica guiada → Checkpoints → Recuperación → Comprueba → Explica → Ayuda progresiva → Reto → Cierre**

## Archivos

- `index.html` — estructura general de la aplicación.
- `styles.css` — diseño responsive y componentes visuales.
- `app.js` — contenido, navegación, ejercicios, test, progreso y `localStorage`.

## Características

- 10 ejercicios progresivos.
- Configuración de Expo usando `blank-typescript`.
- Editor de código con fuente monoespaciada.
- Guardado automático.
- Checkpoints por ejercicio.
- Pistas progresivas.
- Soluciones inicialmente ocultas.
- Test final de 20 preguntas con autocorrección y explicación.
- Persistencia mediante `localStorage`.
- Responsive para ordenador, tablet y móvil.
- Sin frameworks y sin backend.
