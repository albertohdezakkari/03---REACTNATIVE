# Ejercicio 02 - Tarjeta de bienvenida

## Qué he aprendido
- padding crea espacio interior.
- margin crea espacio exterior.
- borderRadius redondea esquinas.

## Respuesta a la pregunta de comprensión
Usaría padding para separar el texto del borde porque esa separación pertenece al interior de la tarjeta. Margin separaría la tarjeta de otros elementos externos.

## Qué he modificado
- He creado una segunda variante con paleta naranja.

## Resultado
Las dos tarjetas comparten estructura y cambian únicamente su tratamiento visual.
