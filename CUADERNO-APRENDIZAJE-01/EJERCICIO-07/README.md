# Ejercicio 07 - Feed de noticias

## Qué he aprendido
- ScrollView permite desplazar contenido.
- Un componente reutilizable conserva estructura y recibe datos por props.

## Respuesta a la pregunta de comprensión
Entre noticias cambian los datos (categoría y título). La estructura visual de NewsCard permanece igual.

## Qué he modificado
- He añadido una cuarta noticia reutilizando NewsCard.

## Resultado
Hay una única definición de NewsCard y cuatro usos con contenidos distintos.
